# Memory System

Controls capture, promotion, and remediation of sprint and project memory.

## What It Controls

Enablement, sprint capture, agent capture, auto-promotion, and remediation mode decide what knowledge is stored and curated.

## Recommended Defaults

Enable memory with deterministic remediation unless you need AI-assisted cleanup.

## Risks And Gotchas

Disabling memory reduces long-term learning; AI remediation consumes routed provider capacity.
