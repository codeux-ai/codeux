# System Memory

Clears memory tiers across every project in the local database.

## What It Controls

Short-term, long-term, and all-memory actions apply globally.

## Recommended Defaults

Use only during local maintenance or after confirming no project needs the retained knowledge.

## Risks And Gotchas

System memory clears are broad and irreversible.
