# Project Memory

Clears selected memory tiers for the active project only.

## What It Controls

Short-term, long-term, and all-memory actions remove progressively broader memory records.

## Recommended Defaults

Clear short-term first when fixing noisy sprint memory; use all-memory only for a full project memory reset.

## Risks And Gotchas

Clearing long-term or all memory removes claims, evidence, and vectors permanently.
