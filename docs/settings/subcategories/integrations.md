# Integrations

Lists provider, git-host, and issue-tracker integrations and exposes manage/add actions.

## What It Controls

Cards show connection state, auth hints, and management entry points; host hints can import detected local settings.

## Recommended Defaults

Configure provider credentials at system scope and use project overrides only for repository-specific git hosts.

## Risks And Gotchas

Imported hints can reveal local auth paths; verify before saving shared configuration.

## Dashboard Link

Open this subcategory from the dashboard docs route at `/docs/user/dashboard/settings#integrations`. The Settings card header links to the matching published docs anchor.
