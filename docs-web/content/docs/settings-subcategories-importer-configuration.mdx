# Importer Configuration

Read-only import settings for Notion, Asana, Linear, Miro, Lucid/Lucidspark, Figma/FigJam, and Mural.

## What It Controls

Enablement, API token or secret value, base URL, provider-specific default workspace/team/project/database/board/document/file identifiers, and search limits decide which external sources appear as importable context.

## Recommended Defaults

Store shared credentials at system scope. Use project overrides only when one project needs a different default identifier or a different read-only token.

## Risks And Gotchas

These importers only attach external context to sprints and do not write back to the source provider. Prefer read-only or least-privilege credentials wherever the provider supports them.
