# Nodes

The **Nodes** page (`/nodes`) manages project-scoped workflow graphs.

Use it to:

- list saved node flows for the active project
- edit nodes and edges on a canvas
- configure nodes through dynamic widget fields
- attach flows to project agents
- validate a graph before saving
- run a flow manually when the runtime exposes execution
- inspect persisted run and per-node status records

Widget fields support text, textarea, numbers, booleans, selects, JSON, secret references, and key-value
entries. Secret fields store references rather than secret values, and rendered run output redacts
secret-shaped keys before display.

When no project is selected, Nodes shows a project-required placeholder because flows, runs, and agent
attachments all belong to a project.
