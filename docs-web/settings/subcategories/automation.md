# Automation

Controls how much Code UX may continue without pausing for operator decisions.

## What It Controls

Automation level sets the broad approval posture; auto-approve plans and auto-resume paused runs handle routine continuation points.

## Recommended Defaults

Use Semi-auto for normal work, Full only for trusted projects, and Always ask for sensitive repositories.

## Risks And Gotchas

More automation can move faster but may continue through a bad plan or stale context before you intervene.
