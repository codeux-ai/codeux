# Onboarding

Reopens the guided setup flow without changing saved settings by itself.

## What It Controls

The action button launches onboarding so you can revisit setup-mode, provider, GitHub, project, and setup prompts.

## Recommended Defaults

Use it when setting up a new machine or after adding provider credentials. First-run setup defaults to Expert mode; Easy mode provides a shorter provider-plus-GitHub path and sends the operator to Chat when finished.

## Risks And Gotchas

Saving new onboarding choices can overwrite the current system defaults, including `appearance.experienceMode`, provider routing, automation defaults, and GitHub workflow defaults.
