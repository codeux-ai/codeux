# Project Context

Names and identifies the active project without changing the stored project id or execution history.

## What It Controls

Project name is editable; project id, source type, and base directory explain how Code UX addresses and enters the workspace.

## Recommended Defaults

Use a clear project name and keep the base directory aligned with the repository root workers should use.

## Risks And Gotchas

Renaming is cosmetic, but an unexpected base directory usually means the project was created from the wrong path.
